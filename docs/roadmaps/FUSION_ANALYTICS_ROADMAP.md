# Fusion & Analytics Roadmap

## Phase 1 — Fusion Foundation

- event ingestion interface
- spatial/temporal matching
- configurable thresholds
- independent-bus rule
- traceable derived cluster model

## Phase 2 — Deterministic Fusion

- frozen scoring formula
- explainable cluster score
- same-bus repeat handling
- lifecycle separation between events and clusters

## Phase 3 — Analytics

- road-damage hotspots
- traffic/congestion analytics
- route indicators
- fleet/urban aggregates

## Phase 4 — Backend Integration

- consume persisted observations
- serve derived intelligence through agreed interfaces

## Phase 5 — Hardening

- deterministic regression tests
- performance measurement
- edge-case handling
