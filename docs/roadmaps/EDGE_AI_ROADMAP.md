# Edge AI Roadmap

## Phase 1 — Edge Foundation

- frame/video provider abstraction
- inference adapter boundary
- deterministic development fixtures
- Edge configuration
- basic tests

## Phase 2 — Perception

- real road/vehicle detection where supported
- object tracking
- confidence handling
- inference performance measurement

## Phase 3 — Event Intelligence

- temporal/multi-frame validation
- event gating
- canonical Event generation
- evidence references

## Phase 4 — Gateway Integration

- hand canonical events to Gateway without database access
- verify offline/retry compatibility

## Phase 5 — Additional Intelligence

- traffic density
- infrastructure observations
- incident-related visual analysis where technically justified

## Phase 6 — Optimization

- latency/FPS
- CPU/GPU/memory
- model optimization
- reliability testing

Only claim capabilities that are actually implemented and evaluated.
