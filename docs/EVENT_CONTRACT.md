# BUSSENSE V2 — Event Contract

## 1. Purpose

The BUSSENSE Event is the standard communication unit between the Edge AI, Edge Gateway, Central Platform, Fusion Engine, Analytics Engine, and GIS Control Tower.

Every meaningful observation generated by the BUSSENSE system must be represented using this event contract.

---

# 2. Core Event Structure

A BUSSENSE event contains:

- Identity
- Classification
- Confidence
- Severity
- Bus/device information
- Location
- Time
- Source
- Status
- Evidence
- Additional metadata
